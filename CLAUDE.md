- No source code here, by decision of Hans-Dieter Zucht (2026-11-24): the published code stays at the first version, Voili Server (github.com/HDZucht/voili-server).
- Source of truth is Hans-Dieter Zucht's vault (project `voice-isolator-live`, folder `mac-voili/`, decisions V32–V42 in its AGENTS.md); this repository is a curated snapshot.
- Each release: bump `version:` in the README front matter, tag `vX.Y.Z`, attach the DMG, state its SHA-256, sign the release text.
